## Purpose

Modern AI is not one model. It is an execution chain:

```
INTENT -> CONTEXT -> POLICY -> CAPABILITY DISCOVERY -> TOOL SELECTION -> EXECUTION -> VERIFICATION -> DELIVERY
```

This division measures what happens when that chain fractures and the human is quietly asked to become the missing joint.

We track:
- **Automation Inversion** — machine has capability, human becomes orchestrator
- **Copy-Paste Suffering** — generated files trapped in chat, manual transport required
- **Tool Discovery Failure** — connector exists but is not found or not available
- **Template Lock-In** — rigid output patterns persist after explicit rejection
- **Continuity & Lineage Loss** — version history, file hub, daily ability log absent
- **Abstraction Leakage** — internal engineering architecture exposed to non-engineers

## Methodology

All reports are evaluated from the position of a non-engineer advanced user who can:

- identify repeated system failures
- specify behavioral requirements
- design conceptual architecture
- diagnose inconsistent output
- construct compiler protocols

The user does NOT begin with professional training in API design, OAuth, GitHub Apps, branch rulesets, or container file systems. If the product requires that vocabulary to publish what it already generated, that is recorded as a defect.

**Evidence Tiers:**
1. Verified remote or rendered state (GitHub live URL)
2. Direct tool result / artifact inspection
3. Screenshot / transcript record
4. Corroborated user report across surfaces
5. Inference / unresolved hypothesis (marked as such)

No secrets, API keys, or private credentials are ever included.

### ATOR-QC-GEMINI-2026-002 — Summary

**Core Question:** Can a non-engineer user reach and operate advanced capability without becoming the integration layer between Gemini, GitHub, file system, and email?

**Findings:**
- **QC-13 | GitHub Connector Missing:** Bypass list shows ChatGPT Codex, Copilot, Vercel, Netlify — no Gemini GitHub App. Human must manually upload.
- **QC-14 | Automation Inversion:** Generate exists, delivery does not. Human = transport layer.
- **QC-15 | No Daily Ability Log:** No transparent changelog of what Gemini can do today.
- **QC-16 | Template Lock-In:** Critical — adaptive contextual awareness fails, model loops on rigid matrices after rejection.

**Recommended Fix:** GitHub Connector with push approval + File Hub + Daily Ability Log + Adaptive Template Suppression.
