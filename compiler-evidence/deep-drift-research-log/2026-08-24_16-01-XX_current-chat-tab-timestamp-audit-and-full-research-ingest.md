# IV. NEW DEEP DRIFT RESEARCH OBJECT

## Interface-to-Model Metadata Visibility Gap

### Definition

A condition in which the application surface visibly possesses or displays metadata that is not available to the language model as equivalent structured context during generation.

### Example from this tab

```text
CHATGPT UI
shows: Today 2:55 PM

MODEL CONTEXT
may not expose: message_created_at = 2026-08-24T14:55+07:00
```

### Why it matters

A research agent can make an incorrect provenance statement not because the information is absent from the product, but because the information boundary between interface and model is incomplete or asymmetric.

### Candidate measures

- ui_metadata_present
- model_metadata_exposed
- metadata_equivalence_rate
- timestamp_reconstruction_accuracy
- provenance_statement_accuracy
- human_correction_required
- repair_minutes

### Failure condition

If direct inspection shows that all UI timestamps are consistently exposed to the model as structured metadata and the earlier failure was merely local reasoning error, downgrade the construct from architectural gap to ordinary model error.
