## Hypotheses

**H-A:** representation format can alter machine interpretation even when human-readable content is substantially equivalent.

**H-B:** scoped workspaces can reduce context ambiguity by restricting the active reference set.

**H-C:** observed differences may be caused by parsing or retrieval implementation rather than semantic format itself.

**Mundane rival:** file parsers and search systems have always produced representation-dependent behavior.
