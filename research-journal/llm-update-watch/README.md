## Core Position

LLM platforms are no longer only conversational systems. The current platform movement shows a larger conversion: memory, retrieval, reusable skills, connected tools, direct document generation, mini-app builders, multi-agent work, and automation are being folded into one creator-work operating layer.

ATOR Institute records this movement as a research object, not as product excitement. A feature release is not neutral. A memory update changes the relation between user and machine continuity. A skill system changes the repeatability of labor. A connector changes what the model can touch. A document export changes whether thought survives movement. A mini-app builder changes the form of publication. A scheduled agent changes the boundary between human presence and machine execution.

Deep Drift Research treats these updates as evidence of workflow drift, artifact drift, memory drift, authorship drift, and platform sovereignty risk.

## Research Question

What happens when LLM platforms become the operating layer for memory, writing, research, files, apps, and action?

The question is not whether a model sounds intelligent. That question belongs to the carnival booth. The serious question is whether human thought can remain source-linked, canon-aware, versioned, export-tested, and authorially sovereign after it passes through these systems.

## Research Law

The journal follows these working laws:

### 1. Chat Output Is Not Canonical Artifact

A chat answer is not a final research object. A canonical artifact requires source linkage, active canon, compiler or skill version, provenance, version lineage, export verification, and destination record.

### 2. Retrieval Is Not Canon

Retrieved context may support work. It may not silently become canon. Every serious output must distinguish raw source, memory, retrieved context, inference, and active canon.

### 3. Skills Are Procedures, Not Decorations

Every serious skill must declare version, trigger, dependencies, compatible canons, incompatible canons, inputs, outputs, and failure conditions.

### 4. Autonomous Agents Cannot Alter Canon

Scheduled agents, background workers, triggers, and automated runs may collect, compare, index, flag, draft, and test. They may not alter canon, rename terminology, adopt hypotheses, overwrite raw source, change writing DNA, or publish high-risk claims without explicit human adoption.

### 5. Artifact Sovereignty Requires Lineage

No DOCX, PDF, slide deck, app, spreadsheet, or Site becomes canonical until Deep Drift records its source IDs, active canon, compiler and skill versions, platform or model, transformations, evidence state, export verification, version, and destination.

### 6. Clipboard Is Transport, Not Archive

Copy-paste remains useful. It is not provenance infrastructure. It is a temporary bridge, not an archive. A bridge that keeps dropping headings does not deserve theological respect.
