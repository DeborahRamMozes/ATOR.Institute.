## Filing rule

This watch uses one file per calendar day:

```text
research-journal/llm-update-watch/
  README.md
  YYYY-MM-DD.md
```

Every observation inside a daily file begins with its real timestamp:

```text
## HH:MM WIB
```

Use seconds only when known. If the time is unavailable, write `TIME UNKNOWN`. Missing precision is never invented.

Evidence notes, source registry, hypothesis changes, protocol changes, synthesis, provenance, and next tests stay inside the daily file. Do not create separate `logs`, `daily-synthesis`, `evidence-registry`, `protocol-patches`, `templates`, or `data/raw` folder trees.

## Research object

The watch tracks changes that materially alter AI workflow behavior: memory, retrieval, skills, connectors, permissions, artifact generation, DOCX/PDF/spreadsheet/slide export, mini-apps, agents, automation, provenance, migration, model retirement, governance, and execution surfaces.

The working Deep Drift question is not whether a model sounds intelligent. It is whether human intention, source, canon, procedure, permission, state, artifact lineage, and authorship remain recoverable after the work passes through the system.

## Core analytical chain


## Evidence discipline

Provider claim, observed behavior, ATØR interpretation, hypothesis, and validated finding are separate states. A release note does not validate an ATØR theory. Cross-platform similarity does not prove causation.
