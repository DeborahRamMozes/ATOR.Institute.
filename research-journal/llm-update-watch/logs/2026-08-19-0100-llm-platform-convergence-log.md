## SIGNAL

LLM platforms are converging toward creator operating systems. The strongest movement is not a single model release. The strongest movement is the integration of memory, skills, connectors, long-running work, direct artifact generation, mini-app builders, multi-agent execution, and automation.

This convergence matters because it changes the object of AI research. The object is no longer only the generated sentence. The object is the workflow chain that remembers, retrieves, transforms, exports, publishes, schedules, and sometimes acts without the human sitting directly in front of the screen.

## CLAIM

The current LLM field is moving from conversational production into workflow production.

Older workflow:

```text
PROMPT
→ ANSWER
→ COPY
→ PASTE
→ FORMAT
→ SAVE
```

Current platform direction:

```text
MEMORY
→ PROJECT
→ SKILL
→ RESEARCH
→ CONNECTOR

→ ARTIFACT
→ DOCX / PDF / SLIDES / DATA
→ MINI-APP
→ AUTOMATION
```

The old workflow still exists. The old workflow is no longer the main frontier. The new frontier is governed artifact formation.

## FRACTURE

The platform market is strong in execution and weak in authorship discipline.

Most platforms now improve the production chain: they remember, search, package, connect, generate, publish, and automate. The weak point remains the preservation of raw thought, terminology ownership, hypothesis status, canon separation, evidence classification, and version lineage.

A platform-generated file may be useful. It is not automatically canonical. A document that opens successfully is not the same as a document with preserved source lineage. Word did not become a priest because it can display margins.

## PROTOCOL PATCHES TO LOCK

### 1. Skill Composition Law

Every skill must declare:

```text
skill_id
version
trigger
dependencies
compatible_canons
incompatible_canons
inputs
outputs
failure_conditions
```

A skill without compatibility boundaries becomes a canon blender. A canon blender is not intelligence. It is soup with an API key.

### 2. Autonomous Canon Protection Law

Agents may:

```text
research
collect
compare
index
flag
draft
test
```

Agents may not:

```text
alter canon
rename terminology
adopt hypotheses
overwrite raw source
publish high-risk claims
change writing DNA
```

Explicit human adoption is required before any autonomous run changes canon, terminology, hypothesis status, or publication state.

### 3. Artifact Sovereignty Law

No DOCX, PDF, slide deck, spreadsheet, app, or Site becomes canonical until Deep Drift records:

```text
source IDs
active canon
compiler version
skill versions
platform or model
transformations
evidence state
export verification
version
destination
```

Chat output is not canonical artifact. Clipboard is not archive. A copied paragraph is a traveler without passport.

### 4. Action Ledger Law

Every connected or autonomous action must record:

```text
agent_id
tool
trigger
read scope
write scope
source IDs
permission
action performed
result
risk
rollback target
```

Tool use without ledger is not productivity. It is a small machine haunting with calendar access.

### 5. Evaluation Harness Law

Every compiler and skill should be tested for:

```text
canon fidelity
terminology fidelity
raw-source fidelity
hypothesis-status fidelity
evidence-classification accuracy
artifact-lineage accuracy
export survival
visual-identity fidelity
action and provenance completeness
```

The test does not ask whether the output sounds good. Slop can sound good. The test asks whether the work survived the machine.

### 6. Worker Trust Law

Parallel agent quantity never equals truth.

Every multi-agent workflow must record:

```text
worker_id
assigned scope
source partition
model or tool
result
confidence
contradictions
verification method
accepted or rejected status
final reconciler
```

One hundred agents can still produce one hundred coordinated mistakes. Scale is not epistemology.

### 7. Derived Action Lineage Law

Every automated chain must preserve:

```text
origin_event
trigger
source artifact
worker or agent invoked
transformation
new artifact
external action
result
rollback state
```

No downstream output may lose its upstream origin.

### 8. Local Source Authority Law

When an agent operates on local files, the original local file remains source authority.

Record:

```text
path or reference
content hash where possible
read or write permission
pre-action version
performed transformation
post-action version
rollback copy
```

Agent memory must never silently replace the file itself.
