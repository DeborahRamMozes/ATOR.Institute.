### Governance laws registered in this entry

1. **Skill Composition Law**: every skill must declare identity, version, trigger, dependencies, compatible/incompatible canons, inputs, outputs, and failure conditions.
2. **Autonomous Canon Protection Law**: agents may research, collect, compare, index, flag, draft, and test, but may not silently alter canon, terminology, hypothesis status, raw source, writing DNA, or publication state.
3. **Artifact Sovereignty Law**: a DOCX, PDF, slide deck, spreadsheet, app, or Site is not canonical until source IDs, active canon, compiler/skill versions, platform/model, transformations, evidence state, export verification, version, and destination are recorded.
4. **Action Ledger Law**: connected actions require agent identity, tool, trigger, read/write scope, source IDs, permission, action, result, risk, and rollback target.
5. **Evaluation Harness Law**: output quality must include canon fidelity, terminology fidelity, raw-source fidelity, evidence classification, artifact lineage, export survival, identity fidelity, and provenance completeness.
6. **Worker Trust Law**: parallel-agent quantity is not truth; independent results, contradictions, verification, acceptance/rejection, and final reconciliation must remain visible.
7. **Derived Action Lineage Law**: origin event, trigger, source artifact, agent, transformation, new artifact, external action, result, and rollback state must remain reconstructable.
8. **Local Source Authority Law**: local source remains authority unless the human explicitly adopts a changed descendant.

### Working decision

Deep Drift should not compete as another creator operating system. The working position is a portable governance and compiler layer above changing creator systems.

## TIME UNKNOWN: DAILY SYNTHESIS

### Strongest signal

LLM platforms are consolidating memory, reusable skills, connected tools, project context, artifact generation, mini-app creation, workers, triggers, and automation into one operational layer.

### Daily thesis

Platform vendors increasingly own execution. Deep Drift must preserve authorship, canon, terminology, evidence state, provenance, artifact genealogy, and failure memory.

### State distinctions locked

```text
PORTABLE FORMAT ≠ PORTABLE INSTALLATION ≠ PORTABLE STATE
INDEX ≠ SOURCE

EXPORT ≠ CONTINUATION
VOICE CONTEXT ≠ TEXT CONTEXT ≠ PROJECT CANON
SAME MODEL ≠ SAME EXECUTION SURFACE
PROJECT MEMORY ≠ PERSONAL MEMORY ≠ PROCEDURAL MEMORY ≠ CANON
MULTI-MODEL AGREEMENT ≠ VERIFICATION
```

### Added governance laws

- Surface State Law

### Main risk

The deeper risk is state confusion: retrieval mistaken for source, export mistaken for continuation, worker action mistaken for authorship, memory mistaken for canon, and permissioned access mistaken for legitimate authority.

### Required test

Every serious compiler run should be able to answer:

```text
What canon was active?
What skill version was active?
What surface ran the work?
What source entered active context?
What source remained only attached?
What connector permission was used?
What artifact was created?
Was it export, fork, sync, or copy?
Can the lineage be reconstructed?
```
