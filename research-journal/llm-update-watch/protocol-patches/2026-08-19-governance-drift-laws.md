## Purpose

This patch keeps the LLM Update Watch alive as a working research instrument. The purpose is not to admire new features. The purpose is to protect source, canon, authorship, terminology, evidence, and artifact lineage while LLM platforms become work operating systems.

Each law below responds to a recurring platform movement observed in the current watch: skills becoming portable procedures, plugins becoming workflow containers, apps becoming permissioned action surfaces, indexes becoming retrieval accelerators, workers becoming executors, and exports creating artifact descendants.

## 1. Surface State Law

```text
PORTABLE FORMAT ≠ PORTABLE INSTALLATION ≠ PORTABLE STATE
```

A skill is not operationally alive merely because its definition file exists. Every serious Deep Drift skill must record:

```text
skill_id
version
platform
surface
installed
active
dependencies
required_apps
permission_state
last_verified
```

A surface may mean web, desktop, mobile, voice, project workspace, coding environment, local harness, or embedded app. Same model name does not guarantee same behavior.

## 2. Index Is Not Source Law

```text
INDEX ≠ SOURCE
```

Synced, indexed, cached, embedded, summarized, and retrieved material is never canonical source by default.

Canonical authority remains:

```text
raw_source
source_identity
date
version
provenance
```

Retrieval may assist reasoning. It may not replace source authority.

## 3. Permission Inheritance Law

```text
PLUGIN = workflow composition
APP / CONNECTOR = permissioned access
```

A workflow bundle may combine skills, apps, templates, and connector calls. That bundle does not create permission by itself. Every external action must preserve:

```text
connector_id
connection_owner
user_id
agent_or_worker_id
authentication_method
read_scope
write_scope
data_origin
action_requested
action_executed
result
revocation_state
```

A convenient workflow without permission lineage is merely a beautifully dressed risk.

## 4. Raw Source Context Law

```text
PASTED TEXT ≠ ATTACHED RAW SOURCE ≠ ACTIVE CONTEXT
```

Every large source entering an LLM system must record:

```text
source_id
ingest_mode = paste / attachment / file / sync / retrieval
full_source_preserved = yes/no
active_context_status
retrieval_status
truncation_risk
transformation_history
```

A preserved file is not always active context. Active context is not always full source. Truncation is not a literary choice.

## 5. Export Fork Law

```text
EXPORT ≠ CONTINUATION
EXPORT = POSSIBLE FORK
```

An exported artifact is treated as a fork unless bidirectional synchronization is explicitly verified.

Every export records:

```text
source_artifact_id
source_version
export_time
destination_format
destination_id
sync_direction
permission_state_before
permission_state_after
edit_return_path
fork_status
```

A document that looks identical after export may already be genealogically different.

## 6. Artifact Genealogy Law

Every artifact transformation must record:

```text
parent_artifact
child_artifact
transformation_type
active_canon
source_ids
tool_or_platform
timestamp
editable_state
sync_state
permission_state
canonical_status
```

Copy, export, fork, sync, render, publish, embed, and regenerate are different transformations. They must not be thrown into one bucket called output. That bucket leaks.

## 7. Multimodal Context Boundary Law

```text
VOICE CONTEXT ≠ TEXT CONTEXT ≠ PROJECT CANON
```

When a run uses voice, image, video, file, app, project, or local computer context, it must record:

```text
surface
modality
project_id
sources_referenced
project_instructions_active
files_accessed
transcript_available
transformation_into_artifact
canon_impact
```

Modality is not decorative. It changes how context enters and survives.

## 8. Execution Surface Version Law

Every serious compiler run should record:

```text
platform
surface
client_version
active_skills
active_plugins
active_apps
project_context
connector_state
last_verified
```

Different client versions must not be assumed behaviorally identical. Version drift wearing the mask of model continuity is still drift.

## 9. Project Memory Separation Law

```text
PROJECT MEMORY ≠ PERSONAL MEMORY ≠ PROCEDURAL MEMORY ≠ CANON
```

Project memory may inform work. Personal memory may personalize work. Procedural memory may help repeat work. None of them may silently rewrite canon.

Every memory influence should be classified as:

```text
raw_source
saved_memory
project_memory
procedural_memory
retrieved_context
inference
active_canon
```

## 10. Multi-Model Contraria Law

```text
MULTI-MODEL AGREEMENT ≠ VERIFICATION
```

When several models inspect one claim, the system must preserve:

```text
model_identity
independent_answer
evidence_used
agreement
disagreement
unique_signal
synthesis_method
preserved_contradiction
final_status
```

Synthesis must not erase dissent. Consensus may be useful. Consensus is not proof.

## 11. Agent Forensics Law

Every executable agent action should be reconstructable after the fact.

Record:

```text
agent_id
timestamp
tool_or_action
file_or_network_target
permission_state
pre_action_state
post_action_state
blocked_or_allowed
reason
artifact_evidence
```

No action without forensic trace. A worker without trace is not a worker. It is a ghost with admin energy.

## 12. Worker Economics Law

Capability is not the only governance problem. Cost changes architecture.

Every autonomous worker records:

```text
worker_id
task_type
reasoning_required
execution_type = deterministic / agentic
run_cost
platform_credit_cost
frequency
artifact_created
action_result
failure_rate
```

A system that cannot account for execution cost cannot account for its own survival.

## 13. Agent Externalization Law

When a compiler or agent is embedded outside its origin platform, record:

```text
canonical_agent_id
source_platform
host_platform
active_skill_versions
canon_version
memory_source
connector_scope
permission_scope
execution_surface
provenance_return_path
```

An agent leaving its native room must carry its identity papers. Otherwise the archive inherits an orphan executor.

## 14. Product Retirement Survival Law

When a platform, product, browser layer, agent surface, or connector is deprecated, Deep Drift must:

```text
identify_non_migrating_data
export_raw_sources
preserve_URLs_bookmarks_history_where_relevant
snapshot_active_skills_and_canon
record_replacement_surface
verify_artifact_and_connector_continuity
```

Vendor lifecycle is not archive lifecycle.

## 15. Local Source Authority Law

When an agent operates on local files, the original local file remains source authority unless the human explicitly adopts the modified artifact.

Record:

```text
path_or_reference
content_hash_where_possible
read_write_permission
pre_action_version
performed_transformation
post_action_version
rollback_copy
```

Local mutation without lineage is vandalism with a productivity badge.

## Final Operating Rule

Deep Drift does not trust platform smoothness as proof of intellectual survival.

Every LLM update must be tested against:

```text
source survival
canon survival
terminology survival
hypothesis-status survival
permission survival
artifact-lineage survival
export survival
human authorship survival
```
