# PyrroxEngine

PyrroxEngine is the ATOR / Deep Drift documentation node for preserving AI research conversations as structured archive material.

## Origin

This node comes from the Chatjipiti Singh and Gemini workflow experiment.

The experiment asked a simple question:

```text
Can a long AI conversation become a structured research document instead of staying trapped inside chat?
```

## Core Compiler Line

```text
raw chaos -> preserved sequence -> readable archive -> evidence object
```

## What It Preserves

- dialogue sequence
- code blocks
- tables
- screenshots or image references
- timestamps
- correction cycles
- document structure

## Workflow Lesson

A custom AI persona is not automatically a working app.

For Deep Drift, a real archive tool must:

1. receive raw conversation material,
2. preserve the order,
3. keep important formatting,
4. produce a readable document,
5. keep the research trail visible.

## Archive Rule

```text
SOURCE FIRST
STRUCTURE SECOND
SUMMARY ONLY IF REQUESTED
```
