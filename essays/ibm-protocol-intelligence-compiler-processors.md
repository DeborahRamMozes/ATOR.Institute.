### 2.1 Computational Nexus: Transformer Limitations and Context Decay

The systemic vulnerabilities of contemporary Large Language Models are directly traceable to
the mathematics of the self-attention mechanism within Transformer architectures.4

Autoregressive token generation computes the probability of the next token `x_t` conditioned on the entire history of preceding tokens `x_<t`:

```math
P(x_t \mid x_{<t}) = \mathrm{Softmax}(f(x_{<t}))
```

While this mechanism allows for remarkable contextual adaptability over short sequences, it
introduces severe architectural vulnerabilities as context length scales.
The first vulnerability is context decay. In an unconstrained autoregressive model, the attention
weight distributed to any single, critical node (for example, a discrete logical unit like the D/E
Node in a complex compilation tree) diminishes as a function of sequence length `k`. As the sequence length `k` approaches infinity, the mutual information `I` between the compiled core concepts `C` and the newly generated data `D` undergoes exponential attenuation:

```math
\lim_{k\to\infty} I(C \otimes D) = 0
```

This context decay triggers "context frustration"-a state where the model, overwhelmed by
unstructured context, begins to prioritize local statistical correlations over global structural rules,
resulting in severe semantic drift and hallucination .
The second vulnerability is the lack of syntactic determinism. Because Transformers treat
programming syntax, mathematical symbols, and natural language as undifferentiated
