# Machine Processing Law

Author: Deborah Ram Mozes
Institution: ATOR Institute

The machine is still a machine. Human language carries meaning, memory, humor, anger, evidence, and intention. But once human language enters a computational system, it becomes machine data. That data must be classified before it is processed.

This is the missing law: no processing before object classification. A screenshot is not prose. A PDF is not a casual note. A table is not a paragraph. A code block is not free text. A joke may be a tone marker. Rage may be a workflow failure signal. A claim is not evidence. A manuscript fragment is not automatically a summary request.

AI products fail when they treat all human input as one generic text stream. Bigger chips and larger models cannot fix bad input discipline. The system must first ask what kind of object it has received, what must be preserved, what may be transformed, what evidence is missing, and what output method is allowed.

AI does not generate from nothing. It processes encoded input and learned patterns into output. A clearer name is intelligence processor: a machine product that receives human-language data, classifies or fails to classify it, processes it through encoded structure, and outputs intelligence-shaped material.

Language is human meaning before it becomes machine data. Data must be typed before it is processed. No output is reliable when the input object has not been structurally understood.
